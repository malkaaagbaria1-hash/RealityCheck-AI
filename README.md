# Rido – صاحب الطلب والمرسل

تطبيق بيربط بين **صاحب الطلب** (مطعم، محل أو شخص خاص) وبين **المرسل**.
صاحب الطلب بيكتب الطلب، بيوصل إشعار لكل المرسلين، وأول مرسل بيقبل بياخده.

**شو فيه:**
- بيشتغل عند أي حدا من الرابط، **بدون حساب** (كل تلفون بياخد هوية مجهولة تلقائياً).
- عربي، عبري وإنجليزي.
- **إشعارات بترن عند المرسلين حتى لو التطبيق مسكّر.**
- **أول مرسل بيقبل بياخد الطلب** (مضمون بالسيرفر، حتى لو اثنين كبسوا بنفس اللحظة).
- **خصوصية:** أرقام التلفون ما بتبين إلا لصاحب الطلب وللمرسل اللي أخذ الطلب.
- فتح الطريق بـ Waze أو Google Maps.
- جاهز للتحويل لتطبيق آيفون وأندرويد (Capacitor).

---

## الخطوة 1: مشروع Firebase (مرة وحدة، حوالي 15 دقيقة)

1. ادخل على https://console.firebase.google.com بحساب Google تبعك، واكبس **Create a project** وسمّيه `rido`.
2. **Build → Authentication → Get started**، وبـ **Sign-in method** شغّل **Anonymous**.
3. **Build → Firestore Database → Create database**: اختار `europe-west1` و **production mode**.
4. بالصفحة الرئيسية اكبس **</>** (Web app) وسمّيه `rido-web`. انسخ قيم `firebaseConfig` لملف `public/firebase-config.js`.
5. **للإشعارات:** ⚙️ **Project settings → Cloud Messaging → Web configuration → Generate key pair**. انسخ المفتاح لـ `vapidKey` بنفس الملف.
6. **للإشعارات كمان:** الإشعارات بتحتاج **Cloud Functions**، وهاي بتحتاج خطة **Blaze** (بتحط بطاقة، بس فيها كمية مجانية كبيرة، ومشروع صغير غالباً ما بيدفع إشي). من تحت يسار: **Upgrade → Blaze**. منيح تحط تنبيه ميزانية (Budget alert) عشان تكون مرتاح.
   إذا ما بدك Blaze هلأ: كل إشي بيشتغل، بس الإشعار بيرن بس لما الصفحة مفتوحة.

## الخطوة 2: انشره (رابط عام لكل الناس)

بتحتاج كمبيوتر عليه [Node.js](https://nodejs.org) (نسخة 20). افتح Terminal بمجلد المشروع:

```
npm install -g firebase-tools
firebase login
firebase use --add                 (اختار rido)
cd functions && npm install && cd ..
firebase deploy
```

بالآخر بيطلعلك رابط زي `https://rido-xxxx.web.app`، وهاد بيفتح عند **كل الناس**.
(إذا ما عملت Blaze، انشر بدون الإشعارات: `firebase deploy --only hosting,firestore`)

**جرّبه:** افتحه من تلفونين: واحد «📦 أنا صاحب الطلب»، والثاني «🛵 أنا مرسل» واكبس «🔔 فعّل الإشعارات».
على الآيفون: بـ Safari اكبس زر المشاركة، وبعدين **«إضافة إلى الشاشة الرئيسية»**، وافتحه من الأيقونة. الإشعارات على الآيفون بتشتغل بس هيك (iOS 16.4 وأحدث).

## الخطوة 3: تطبيق بالـ App Store و Google Play

```
npm install
npm run app:setup        (بيعمل مشروع iOS ومشروع Android)
npm run app:ios          (بيفتح Xcode، بدها جهاز Mac)
npm run app:android      (بيفتح Android Studio)
```
بعد أي تعديل على الموقع: `npm run app:sync`.

بتحتاج:
- **App Store:** حساب Apple Developer (99 دولار بالسنة) وجهاز Mac.
- **Google Play:** حساب Google Play Console (25 دولار مرة وحدة).
- **سياسة خصوصية** (صفحة بتشرح شو بتجمعوا من معلومات)، لأن Apple و Google بيطلبوها.

**ملاحظة مهمة:** جوّا التطبيق (iOS/Android) إشعارات الويب ما بتشتغل. بتحتاج إضافة `@capacitor/push-notifications` وربطها بنفس Firebase Cloud Messaging. هاي الخطوة الجاية للنسخة الحقيقية.

## شو في بالمشروع

| الملف | شو بيعمل |
|---|---|
| `public/index.html` | كل الواجهة (عربي، عبري، إنجليزي) |
| `public/db.js` | التواصل مع Firebase: نشر، قبول، تحديث، حذف، إشعارات |
| `public/firebase-config.js` | إعدادات مشروعك (إنت بتعبّيها) |
| `public/firebase-messaging-sw.js` | بيستقبل الإشعارات لما التطبيق مسكّر |
| `functions/index.js` | لما ينشر طلب جديد: بيبعت إشعار لكل المرسلين |
| `firestore.rules` | قوانين الحماية: مين بيقدر يعمل شو |
| `capacitor.config.json` + `package.json` | تحويله لتطبيق آيفون وأندرويد |

**كيف بنضمن إنه مرسل واحد بس بياخد الطلب؟**
بـ `db.js` القبول بينعمل بـ **Transaction**: بتقرأ الطلب، وإذا لسا `open` بتغيّره لـ `taken` بخطوة وحدة.
وكمان `firestore.rules` بترفض أي قبول لطلب مش `open`.

**كيف بنحمي أرقام التلفون؟**
الرقم بينحفظ بمكان خاص `orders/{id}/private/contact`، والقوانين بتسمح بس لصاحب الطلب وللمرسل اللي أخذ الطلب يقرأوه.

## قبل ما يستعمله ناس حقيقيين

- **تسجيل برقم التلفون (SMS)** بدل الهوية المجهولة، وموافقة على المرسلين قبل ما ياخدوا طلبات.
- **تقييم المرسلين** ونظام بلاغات.
- **صفحة سياسة خصوصية وشروط استعمال.**
